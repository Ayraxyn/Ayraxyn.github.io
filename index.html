Pay Full Attention when Threading!

The following image depicts a user perfoming knitting using a pair of knitting
sticks. Making a single mistake in this art medium is no joke - it could take
you hours to undo and there is no guarantee that that might even be possible.
In some mediums, destroying the fiber bonds between the fabric, felt or wool
can be fatal resulting in a full restart. In other cases, making the fiber
bonds too strong also can call for a restart. Luckily, in knitting the wool
is rather lenient, where any error can be amended with enough time.

Part 1: Introduction

Firstly, there are more types of felting than just knitting! Some of these other forms include but is not limited to Crochet Art, Macrame, Spinning, and felting! Which will be main focus of this website. However, among all the fiber art types, they all achieve the same goal within the same medium - as the name suggests, all these art forms use fabric, wool and felt like materials! Most of these mediums also involve the use of a needle or an object able to weave between the fiber of these materials, so if you. planning to start your fiber art journey, do get used to poking yourself!

Part 2: The First Thread

The oldest form of fiber art also happens to be the type we will be discussing today! Felting was theorized to first have been started in 6000BCE in Antolia, however any actual proof of items were only found in 1800BCE in China. Felt back then was primarily used to create horse blankets, clothing and gone along with jewelry.
